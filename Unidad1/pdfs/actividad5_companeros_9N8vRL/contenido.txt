Auditorias
Auditar significa examinar procesos, cuentas,etc. En el caso de la base de datos “auditar” es
un proceso vital para mantener la integridad de los datos, es una acción importante para la
triada de la seguridad y cumplir con requisitos como por ejemplo la certificación de la norma
ISO 27000-1.



Auditar en SQL SERVER
En SQL SERVER existen diversas formas de auditar, Unas más óptimas que otras.
   ●​ Profiler: actualmente en desuso.
   ●​ C2: el cual genera muchos archivos y no se recomienda trabajar con el
   ●​ Auditoría en el servidor/base de datos
   ●​ Eventos extendidos



SQL Profiler
SQL Profiler no viene integrada en el management studio, viene en una aplicación aparte.
dentro de él se manejan los trece los cuales generan archivos con extensión .trc
