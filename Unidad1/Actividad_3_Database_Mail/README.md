## 1. Introducción

SQL Server es un sistema de gestión de bases de datos relacional de Microsoft que permite almacenar, consultar y administrar información. Database Mail es una característica de SQL Server que permite enviar mensajes de correo electrónico mediante un servidor SMTP.

En esta práctica se verificará el entorno de SQL Server y se configurará Database Mail de forma controlada. Posteriormente se realizará un envío de prueba y se revisará el historial generado por el servicio.

---

## 4. ¿Qué es Database Mail?

Database Mail es el componente de SQL Server que envía correo electrónico a través de perfiles y cuentas SMTP configuradas en la base de datos `msdb`. Puede utilizarse para alertas, notificaciones operativas, resultados de tareas, reportes y automatizaciones. En un entorno empresarial facilita el monitoreo de procesos y la comunicación de eventos relevantes a administradores, usuarios o equipos de soporte.
