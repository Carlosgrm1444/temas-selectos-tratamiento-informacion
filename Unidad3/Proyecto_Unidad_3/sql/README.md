# Códigos SQL de la presentación

Esta carpeta reúne los códigos que aparecen en la presentación del Proyecto Unidad 3.

1. `01_subconsultas_encriptados.sql`: dos procedimientos con subconsultas, `WITH ENCRYPTION` y `TRY...CATCH`.
2. `02_if.sql`: dos procedimientos con la estructura `IF`.
3. `03_while.sql`: dos procedimientos con la estructura `WHILE`.
4. `04_case.sql`: dos procedimientos con la estructura `CASE`.
5. `05_indices.sql`: ejemplo de índice no agrupado y comparación con `STATISTICS IO` y `STATISTICS TIME`.

Ejecutar los archivos en ese orden, después de tener creada la base `pepsi_distribucion` y las tablas del esquema `proyecto_u2`.
